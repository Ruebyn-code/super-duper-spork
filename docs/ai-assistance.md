# AI assistance

Open **Settings → AI assistance** in the intended company. Head Office has access by default; custom roles can be granted **AI assistance settings** without gaining course or checklist authoring permissions. Each company keeps its own key and usage limits, including when hosted inside an Opstack network.

Add an OpenAI API key with access to **GPT-4.1 mini**, choose an estimated monthly budget in **USD** and a maximum number of drafts, enable drafting, and save. The default budget is US$10 and the default draft limit is 100. Saving settings makes no provider request. A blank key field keeps the saved key; disable AI and select Remove to delete it. Keys are saved only in private server data files with mode 0600, and are never included in API responses or browser storage. Protect server data and backups as credentials.

**Create with AI** is available to the corresponding checklist/course authors, both beside the create control and inside each builder. Enter requirements and optionally paste approved reference notes. Generating sends only this text and the fixed output instructions to OpenAI's chat completions endpoint, using the pinned `gpt-4.1-mini-2025-04-14` model and structured JSON output. It does not search app records, upload files, call tools, create schedules, publish courses or assign training. OpenAI receives the text explicitly submitted by the author; account-level provider retention policies still apply. The request uses `store: false`.

The preview is read-only. **Open draft in builder** creates a normal editable draft after flushing existing valid builder changes; normal autosaving, publishing, planner and assignment permissions still apply. Closing the preview creates no app content. Course sections, lessons, quiz choices and correct answers, and checklist response types are validated with the normal app models. Review generated facts, procedures and quiz answers before publishing or scheduling.

Limits reset at the start of the month in Melbourne time. Before a request, the app atomically reserves an estimate based on a conservative UTF-8 input bound (including schema overhead) and a maximum of 10,000 output tokens. Concurrent requests cannot spend the same remaining estimate. Confirmed token usage replaces the reservation; failed requests without confirmed usage keep the reservation and every attempted provider request counts toward the draft limit. No automatic provider retry is made. Request IDs coalesce concurrent retries and return the same recently cached result without charging again; older or uncertain results require an explicit new request. In-flight requests settle against their original month and preserve later settings changes. The last 12 results are cached privately; usage references are kept for roughly three months.

Budget estimates default to US$0.40 per million input tokens and US$1.60 per million output tokens. Verify current pricing against the OpenAI account and update the rates in **Cost estimates and billing** if needed. The app cannot know taxes, exchange rates, negotiated prices or other use of the same OpenAI account. These are company app limits based on configured estimates, not a guarantee of the provider's final bill. Configure OpenAI billing controls as appropriate. ChatGPT subscriptions do not include API charges.

Tests use a fake provider and isolated data; they do not make paid requests. A real-key generation must be checked after configuring the deployed app. No environment API key is automatically consumed or shared between companies.
