## Stock transfer approvals

Home automatically shows pending incoming stock transfers above the dashboard sections for the selected location’s assigned managers. The account also needs Home, View stock transfers and Receive stock transfers permissions. A Manager dashboard or supervisor/Head Office role alone does not qualify; assign the user in Location settings → Managers. This operational panel works with either dashboard profile and does not change saved company layouts.

Select **Review transfer** to check sender, destination, immutable item names, units, receiving quantities and notes. **Approve receipt** explicitly confirms all items have arrived and applies the existing stock/cost movements. Home shows whether saved costs move, without exposing prices or financial totals; full transfer history remains available through its ordinary permissions. Close/Cancel/Escape never approve. Only the first five pending transfers appear on Home; **All transfers** opens the full list.

Pending transfers refresh read-only on focus, visibility changes, shared transfer updates and every 30 seconds. Approved/cancelled transfers leave the list. Request IDs survive an uncertain receipt response for an explicit safe retry, late reads cannot restore approved rows, and removed manager assignments block an already opened Home approval. Native location, permission, CSRF, receipt revision, count-snapshot and kiosk guards remain in force.
