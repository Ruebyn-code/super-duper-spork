Home is a company dashboard for the selected location. The new default includes a greeting, quarter totals and completed-week averages, six quick links, Attention, today’s checklists, your upcoming published shifts and the ordering budget. It uses the company’s colours and font. Existing appearance edits, metric visibility and calculations remain in place.

**OpStack intelligence** leads Home with a daily briefing card, using the selected company’s intelligence palette, tint and font. Opening Home and **Refresh figures** read current, permitted aggregates without making a paid request. **Generate today’s briefing** explicitly uses the existing company key, budget and request cap. It covers trading status, recorded Daily sales through yesterday, currently open checklist windows, your outstanding/overdue training, your unread-message count and this week’s saved invoice counts, when you have the relevant permissions. Sources and supporting figures explain coverage and show unavailable data explicitly. No staff names, course/checklist contents, message bodies, invoice files or credentials go to AI.

Generated commentary cites the exact supporting figures and links to ordinary app pages. Suggested next steps remain suggestions: generating or reading a briefing never acknowledges Comms, starts work, changes sales/prices or sends reports. **Ask a question** opens the shared intelligence search. A briefing is reused without another AI call only for the same account, company, location, Melbourne date, permissions and unchanged source figures. Changed data clears the old commentary and requires explicit generation; incomplete sources are not treated as zero. Current access, required reading, company enablement and source versions are checked again after generation. Your saved dashboard sections, appearance, greeting and daily-sales editor remain separate.

On a computer, choose **Edit Home** on Home, or **App edit** in the blue account dropdown. Choose **Add section** on the page, search the catalogue and select a section. Configure its title, optional note and full, half or third width directly in the card. Quick links can contain any permitted destination; App module adds one focused shortcut. Choose **Apply section** to save the configuration automatically for everyone in that company. **Add below** inserts immediately after the chosen section. Hold and drag a section or quick link to rearrange it; keyboard users can select it and use Alt + arrow keys. Section changes and rearrangements have separate Undo controls.

Sections include sales progress, weekly financial performance, placed orders, stock and suppliers, transfers, unread Comms, active checklists, shifts, timesheets, leave and availability, Knowledge Library, Labels, invoice bundles, users, locations and companies. The picker also offers headings and notes. Permission checks determine available options and data. Home does not mark posts/messages read, start checklists, clock staff in or out, print labels, place orders or add expenses.

**Reset sections** restores the new default section list. It keeps company colours, wording, fonts, images, spacing settings and saved arrangements. Additional appearance controls remain in **App edit → Home layout**, including density, desktop quick-link columns, page width, spacing, corners, metric visibility, date labels and notes. Phones use the company layout with two quick-link columns; editing is hidden and roster links use the existing roster popup.

Home section settings live in the selected company’s `home-dashboard.json`, separately from business records and `layouts.json` arrangements. Company and network storage remain independent. Writes require appearance permission, a session CSRF token and the current revision. If another tab saves first, local changes are preserved and a conflict is shown; **Reload saved sections** explicitly discards the local draft. Failed saves can be retried. Custom section titles and notes are entered data, so App edit wording replacements cannot change them; styling remains customisable.

Quarter and ordering figures retain their existing calculations: current-quarter sales/expense percentage, all-time placed order totals, completed Monday–Sunday weeks for quarter averages, and the Sunday midnight ordering forecast change. Sales progress compares actual and expected sales for the same recorded days. Financial performance uses the weekly report, without feeding projections. Recent orders show the signed-in user’s placed orders only. All other widgets use their existing permission-checked, location-scoped APIs. Recent posts means the latest page of 25 posts; the message count remains the full unread message total. Empty/incomplete data is shown explicitly, and failed sections offer Retry.

Use the **+** in a Quick links heading to add shortcuts directly. The searchable picker shows destinations you can access and omits ones already in that section. Selecting a shortcut saves it immediately for the company. The button is available to desktop users with appearance permission; other staff and phones see the saved links. App edit offers backgrounds, images, icons and arrangements. Individual words and numbers do not open appearance controls. Click the Home greeting in App edit to change its company wording; keep {user} once so the account name stays automatic. Hidden, disabled, readonly, inert and protected controls are not appearance targets. Existing saved wording remains in place when styling or linking matching parts.


In desktop App edit, drag a section’s bottom-right corner to change its width and minimum height. Widths snap to the page columns; content always remains visible. Arrow keys on the corner adjust the size, Shift increases height steps, and double-click restores automatic sizing. Home saves section dimensions with its other section settings; Undo restores the previous dimensions. Cards stack below shorter neighbours, and Add below inherits the selected section’s width and column, so it appears directly underneath. Resizing keeps open section configuration drafts intact. Phone layouts keep their normal single-column, automatic-height presentation.

The appearance popup puts This part and Matching parts beside one-click Original, Primary, Secondary and Custom colour choices. More options contains surrounding-target selection and shared background groups. Background image options start collapsed unless an image is already saved. The popup retains the transparency slider and fixed Save/Cancel actions; individual interface wording remains locked except for the Home greeting.
