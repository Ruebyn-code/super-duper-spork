Opstack console

Manage networks and support from your Opstack account.

Create the first Opstack owner from the terminal on the server running this app:

npm run opstack:owner

On Railway, run this inside the app’s Railway SSH terminal with its existing DATA_DIR. Follow the name, email and password prompts, then reload this page. Network users cannot create Opstack accounts.
