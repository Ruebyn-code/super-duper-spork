Opstack console

Manage networks and support from your Opstack account.

Create the first Opstack owner from the terminal on the server running this app:

npm run opstack:owner

On Railway, run this inside the app’s Railway SSH terminal with its existing DATA_DIR. Follow the name, email and password prompts, then reload this page. Network users cannot create Opstack accounts.

Set up location billing

Connect Stripe to begin.

    Stripe billing setup
    STEP 1 OF 5

    Connect Stripe

    Start in Sandbox to test your setup. Live uses its own key, prices and customers.

    Open Stripe API keys ↗
    STEP 2 OF 5

    Connect payment notifications

    Stripe uses this address to tell OpStack about payments and subscription changes.

    Open Stripe webhooks ↗

    Set APP_ORIGIN on the server to your public HTTPS app address, then redeploy to display this address.

    Events to select in Stripe
    • checkout.session.completed
    • All customer.subscription.* events
    • All invoice.* events
    • charge.refunded

    Choose Your account and snapshot events. Use endpoint API version 2024-06-20 if offered.

    STEP 3 OF 5

    Choose a location, customer and fees

    Manage Stripe prices ↗

    Choose your recurring AUD monthly prices, or enter existing Stripe references under Advanced.

    STEP 4 OF 5

    Complete secure checkout

    Open secure checkout ↗

    The paying customer completes Stripe checkout to authorise payments. Creating a customer or saving a plan does not start a subscription. Checkout links expire after about one hour.

    STEP 5 OF 5

    Finish & enable updates

    Review this location’s current rates and user count, then approve once to enable automatic updates. Quantity changes create prorations for the next invoice.

    Manual connection controls

    Turning off sync does not cancel Stripe subscriptions. Manage cancellations and refunds in Stripe.
