How target levels work

Target level is your location’s average usage from up to four completed Sunday–Saturday weeks, rounded up to whole units or packs. Usage is calculated from Sunday stock + that week’s orders − the next Sunday stock count. Save Sunday counts and place orders as usual; usage updates automatically. With no completed usage weeks, Head Office can set a manual target level in the stock editor for this location. After one completed week, the target level uses that week, then averages two, three and finally four available completed weeks. Missing counts or negative usage need checking; they are excluded. Recommended order = target level − the latest stock count, rounded up to whole units, with a minimum of zero.
